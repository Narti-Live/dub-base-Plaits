VAULT

An FM synth for the deep end: dub chords, stabs, pads and bass. Digitone-style FM, OB-X and Prophet-style filters, a step / Turing machine / Metropolis sequencer that never leaves the key, tape echo, a dark space, drive and glitch.

Headphones or a real system recommended. Desktop browsers run it best.
